# GeoTrade — runtime dependencies (slim, pinned)
#
# Every version here is the exact release the app was booted and tested with.
# Pinned with `==` deliberately: the previous `>=` ranges resolved to different
# versions on the developer machine and on Render, which is what made deploys
# fail with pandas/numpy build errors and silent runtime breaks.
#
# Heavy ML/NLP stacks (torch, transformers, spaCy, sentence-transformers) are
# NOT here — see requirements-ml.txt. All of them are imported lazily behind
# try/except ImportError, so the API boots and serves without them.
#
#   pip install -r requirements.txt              # API + market data + cache
#   pip install -r requirements-ml.txt           # + full NLP/ML intelligence
#   pip install -r requirements-dev.txt          # + tests and linting
